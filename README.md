# ☕ Exercícios de Java

> **Exercícios para compreensão da sintaxe da linguagem, prática de lógica de programação e Programação Orientada a Objetos em Java.**

Este repositório reúne uma coleção de exercícios e desafios práticos desenvolvidos em **Java**, cobrindo desde conceitos fundamentais até manipulação de estruturas de dados e conceitos de POO.

---

## 📌 Sobre o Repositório

O objetivo principal deste repositório é registrar e organizar o processo de aprendizado na linguagem Java. Os exercícios abordam a sintaxe fundamental, algoritmos de lógica de programação, métodos e orientação a objetos com boas práticas de código.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** [Java (JDK 17+)](https://www.oracle.com/java/)
- **IDE / Editor:** IntelliJ IDEA
- **Controle de Versão:** Git & GitHub

## 📂 Organização do Conteúdo

| Categoria / Módulo | Descrição | Principais Tópicos |
| :--- | :--- | :--- |
| **01-Fundamentos-Basicos** | Primeiros passos na linguagem Java | Variáveis, tipos de dados primitivos, operadores aritméticos, entrada e saída com `Scanner` |
| **02-Estruturas-Condicionais** | Tomada de decisões nos programas | Bloco `if`, `else if`, `else`, instrução `switch`, operadores de comparação e lógicos |
| **03-Estruturas-de-Repeticao** | Laços e repetições | Estruturas `for`, `while` e `do-while`, contadores, acumuladores e controle de fluxo (`break` / `continue`) |
| **04-Estruturas-de-Dados** | Armazenamento e organização de dados | Vetores (Arrays unidimensionais), Matrizes (Arrays bidimensionais) e manipulação de índices |
| **05-Metodos** | Reutilização e modularização de código | Modificadores de acesso, parâmetros, retorno de valores, escopo e assinaturas de métodos |
| **06-POO** | Programação Orientada a Objetos | Classes, Objetos, Atributos, Métodos, Construtores, Encapsulamento, Herança e Polimorfismo |

---

## 🚀 Como Executar os Exercícios

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/Walisonjos3/Exercicios-Java.git
   ```

2. **Acesse a pasta do repositório:**
   ```bash
   cd Exercicios-Java
   ```

3. **Navegue até a pasta do módulo e compile/execute o arquivo desejado via terminal:**
   ```bash
   cd 01-Fundamentos-Basicos
   javac NomeDoArquivo.java
   java NomeDoArquivo
   ```
   *(Ou abra a pasta raiz do projeto na sua IDE favorita e execute a classe principal diretamente).*
